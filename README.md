# Aura AI 🤖
### AI-Powered Personal Communication Copilot

> An intelligent Telegram bot that learns your texting style and manages conversations when you're unavailable.

## Features
- 🧠 **AI Brain** — Powered by Groq (Llama 3.3)
- 👤 **Personality Cloning** — Replies in your exact texting style
- 🌐 **Multi-language** — Telugu, Hindi, and English
- 🚨 **Priority Detection** — Alerts you for urgent messages
- 💾 **Memory System** — Remembers conversations across sessions
- 👥 **Contact Profiles** — Different tone for friends, family, professional

## Tech Stack
- Node.js + Telegraf
- Groq AI API (Llama 3.3)
- JavaScript
- dotenv

## Setup
1. Clone the repo
2. Run `npm install` in `/bridge`
3. Create `.env` with your tokens
4. Run `node index.js`
